# MakerHub deep shell

**目标：深度模仿 MakerHub 切割站壳与工作流**（功能与交互对标；内核自研）。

## Foundation gate（已完成）

1. **5 stages（生产加工）**：载入方案 → 板材与设备 → 密排 → 刀路与加工档 → 导出  
2. **左模块轨（对标 MakerHub）**  
   | 模块 | 骨架能力 |
   |------|----------|
   | 生产加工 | 空态 · 5 步流程 · 画布 · 一键导出 |
   | 补板库 | 余料登记 / 删除 · 从当前板材草稿 |
   | 设备管理 | 机型目录 · 详情 · 应用到生产 |
   | 路线管理 | 五步进度 · 工序开关只读 · 作业工序摘要 |
   | 原料管理 | 车间材料库 CRUD · 方案板材/用量 · 从方案同步 |
   | 工艺模版 | 刀具库 CRUD · 作业工序 · 从机型重置 |
   | 参数设置 | 排版默认值 · 应用到生产 · library.json |
3. **车间库**：`%LocalAppData%/CabinetNC/library.json`（`WorkshopLibraryStore`）  
4. **空态 / 导入弹窗 / 一键导出 gate**  
5. **3 panes**：左工程树 · 中画布/NC · 右属性

## Method

- **对照 MakerHub 的可见行为与界面** 做需求与验收  
- **自研** `geom` / `pack` / `ops` / `nc` / UI；磁盘合同以 `cabinetnc.woodjob` 为主  
- 发行物不捆绑第三方专有二进制；能力用自有实现补齐
