# CabinetNC Cut 冒烟测试案例库

## 使用方法

### 前置条件

1. Windows x64，安装 .NET 10。
2. 仓库：`d:\project\cabinetnc-cut`。
3. 示例：`public\samples\demo_woodjob_120.zip`。
4. 启动：

```powershell
$env:Path="C:\Program Files\dotnet;"+$env:Path
cd d:\project\cabinetnc-cut\dotnet
dotnet run --project src\CabinetNC.Desktop
```

### 结果记录

每个案例填写：

- 结果：`PASS / FAIL / BLOCKED`
- 实际结果：
- 截图/文件：
- 操作者与日期：
- 缺陷编号：

严重度：`P0` 会造成错误加工/数据损坏；`P1` 阻断主流程；`P2` 功能退化；`P3` 体验问题。

## 1. 启动与导航

### SMK-001 冷启动

- 风险：P1
- 步骤：
  1. 关闭所有 CabinetNC 进程。
  2. 启动 Desktop。
- 预期：
  - 出现唯一 `CabinetNC Cut` 窗口。
  - 显示空态“尚未载入方案”。
  - Worker 状态最终显示可用或明确错误，不应无响应。
  - 后四个生产步骤不可进入。

### SMK-002 七模块导航

- 风险：P2
- 步骤：依次点击生产加工、补板库、设备管理、路线管理、原料管理、工艺模版、参数设置。
- 预期：每个模块显示对应内容；返回生产加工后空态/作业状态保持。

### SMK-003 无方案阶段门禁

- 风险：P1
- 步骤：未载入方案时尝试点击板材与设备、密排、刀路与加工档、导出。
- 预期：步骤保持禁用；状态提示先载入方案。

## 2. 输入与反馈

### SMK-010 导入 120 板 woodjob

- 风险：P0
- 步骤：点击“打开示例”。
- 预期：
  - 弹窗标题为打开示例成功。
  - 格式为 `cabinetnc.woodjob v2`。
  - Job 为 `JOB-2026-DEMO-120`。
  - 板件 120、板材规格 4、材料种类 4。
  - 警告可读，确认后左侧出现板件。

### SMK-011 手工选择 woodjob zip

- 风险：P1
- 步骤：载入 `public\samples\demo_woodjob_120.zip`。
- 预期：与 SMK-010 相同；文件名显示正确。

### SMK-012 非法包反馈

- 风险：P1
- 步骤：选择 `dotnet\tests\manual\fixtures\invalid_empty.cut.json`。
- 预期：弹出失败对话框，包含路径、错误列表和 `panels[] is empty`；原有作业不应被替换。

### SMK-013 checksum 错误

- 风险：P0
- 步骤：复制 woodjob 解压目录，修改 `parts.json` 后从目录导入。
- 预期：导入失败，明确提示 SHA-256 mismatch；不得静默继续。

### SMK-014 project.db 回读

- 风险：P1
- 步骤：载入方案→密排→保存工程→关闭→打开工程。
- 预期：板件、机型、摆位、NC 恢复；成功弹窗包含恢复摆位数。

## 3. 几何与板件

### SMK-020 板件选择与尺寸

- 风险：P2
- 步骤：载入示例，依次选择普通矩形板和圆角板。
- 预期：画布轮廓、尺寸、板厚、特征数量与检视器一致。

### SMK-021 孔/槽/边拖动

- 风险：P1
- 步骤：拖动孔中心、槽端点、矩形边手柄。
- 预期：拖动实时反馈；松开后尺寸/特征更新；旧密排结果清除。

### SMK-022 旋转 90°

- 风险：P0
- 步骤：选择非方形板，点击旋转 90°，再密排并生成 NC。
- 预期：画布、密排 AABB、DXF、NC 使用相同旋转原点；NC 不得出现意外负 X/Y。

---

## 4. 板材与密排

### SMK-030 板材参数同步

- 风险：P1
- 步骤：进入“板材与设备”。
- 预期：板宽、板长、边距、间距来自 woodjob sheet；机型可选择。

### SMK-031 120 板自动密排

- 风险：P0
- 步骤：进入密排，点击“密排 + 生成加工档”。
- 预期：
  - 产生摆位和 sheetCount。
  - 报告含 engine、利用率、已排/未排、warnings。
  - 无应用崩溃或 UI 长时间假死。

### SMK-032 缺陷区避让

- 风险：P0
- 步骤：对含 `DEF-001` 的橡木板材执行密排。
- 预期：任何板件多边形不与缺陷 AABB 相交。

### SMK-033 补板参与密排

- 风险：P1
- 步骤：
  1. 补板库添加一块可容纳小板件的补板。
  2. 标记 `[Nest]`。
  3. 重新密排。
- 预期：补板进入 sheet 队列；切换为 `[—]` 后不再参与。

### SMK-034 拖动、重叠与回退

- 风险：P0
- 步骤：拖动板件压到另一板件上，保持“允许重叠”关闭。
- 预期：放下后回退原位置并提示阻挡；开启允许重叠后可放置但校验报冲突。

### SMK-035 锁定后重排

- 风险：P0
- 步骤：锁定一块板→记录坐标→应用并重排。
- 预期：锁定板坐标、旋转、sheet 保持；最终布局重新执行多边形校验。

### SMK-036 Clipper2 多边形/间距校验

- 风险：P0
- 步骤：点击“Clipper2 多边形校验”。
- 预期：无冲突时显示通过；有冲突时列出板件对和 sheet，不得只报告 AABB 假阳性。

## 5. 刀路、刀具与 NC

### SMK-040 工序完整性

- 风险：P0
- 步骤：进入“刀路与加工档”。
- 预期：工序表至少包含 contour、drill、groove；画布颜色与工序一致。

### SMK-041 路线开关

- 风险：P0
- 步骤：在路线管理分别关闭 contour/drill/groove，再返回刀路。
- 预期：对应工序从叠画和新生成 NC 中消失；重新开启后恢复。

### SMK-042 应用车间刀具

- 风险：P0
- 步骤：
  1. 工艺模版选择一把刀具。
  2. 点击“应用选中到当前加工”。
  3. 重新生成 NC。
- 预期：NC 中主轴转速和进给使用该刀具；CAM 刀补默认值等于半径。

### SMK-043 轮廓刀补

- 风险：P0
- 步骤：开启“轮廓刀补”，输入 3mm。
- 预期：外轮廓向外偏、内轮廓向内偏；刀路画布与 NC 一致；关闭后恢复原路径。

### SMK-044 CAM playhead

- 风险：P2
- 步骤：点击上一步、下一步、播放、暂停。
- 预期：计数循环；文本含工序/板件/点坐标；画布当前工序黄色高亮并显示位置点。

### SMK-045 旋转 NC 安全

- 风险：P0
- 步骤：对允许 90° 旋转的 120 板示例生成 NC，搜索 `X-` 和 `Y-`。
- 预期：正常板材原点配置下无意外负 X/Y；所有路径在板材范围内。

### SMK-046 NC 预检

- 风险：P0
- 步骤：进入导出→点击预检。
- 预期：正常作业通过；无工序、越界、无效进给会失败并列原因。

## 6. 导出与车间文件

### SMK-050 导出 NC

- 风险：P0
- 步骤：预检通过后导出 NC。
- 预期：文件非空，含 G21/G90、主轴、sheet 注释、M2/M30。

### SMK-051 导出 DXF

- 风险：P1
- 步骤：导出 S1 DXF。
- 预期：R12 文件含 PANEL、HOLE、GROOVE 图层；旋转后坐标与画布一致。

### SMK-052 导出工单

- 风险：P1
- 步骤：导出 HTML 并用浏览器打开。
- 预期：Job、机型、材料、利用率、预检、板件尺寸、sheet、锁定状态可读并可打印。

### SMK-053 一键打包

- 风险：P1
- 步骤：选择导出目录。
- 预期：同时生成 `.nc`、`_S1.dxf`、`_sheet.html`、`.cut.json`；成功弹窗列文件。

## 7. 库与参数

### SMK-060 材料库持久化

- 风险：P2
- 步骤：添加材料→保存库→重启。
- 预期：材料仍存在；`%LocalAppData%\CabinetNC\library.json` 可读。

### SMK-061 刀具库持久化

- 风险：P1
- 步骤：添加刀具→应用→重启。
- 预期：刀具仍在库；再次选择后能驱动 NC。

### SMK-062 参数默认值

- 风险：P2
- 步骤：修改板宽/长、间距、边距、旋转→保存→应用到生产→重启。
- 预期：生产输入框更新；重启后默认值保留。

`001, 002, 010, 012, 031, 035, 036, 040, 042, 043, 045, 046, 050, 051, 052, 053, 060`
